CladisTree

FR (Français)

CladisTree is a cladogram formatting application designed to handle complex trees and manage phylogenetic data.

The software automates the layout of evolutionary trees, links taxonomic data sheets to individual nodes, and integrates geological time scales. It is built to support workflows from initial data import to high-resolution export. Available for Windows, macOS, and Linux.

Overview of Features

Layout and Formatting

  • Standard and "comb" (pectinate) tree drawing modes.
  • Dynamic monophyletic and paraphyletic grouping frames that adjust automatically as new taxa are added.
  • Customizable themes, including dark mode and high-contrast options for accessibility.

Data Management

  • Dedicated data sheets for each taxon to record diagnosis, IUCN threat status, bibliography, and synonymy.
  • Automatic species counting and text formatting (e.g., automatic italics and handling of abbreviations like X. xxx).

Geological Context & Performance

  • Interactive geological time scale ranging from the Precambrian to the present, which adjusts based on the dates entered for the taxa.
  • Optimized for large datasets: multi-sheet tree structuring, specific trackpad navigation, keyboard shortcuts, and Xmind file import.
  • Export options: High-resolution images, CSV, and PDF (including the detailed taxon data sheets and time scales).
