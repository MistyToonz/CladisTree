# CladisTree

**CladisTree** est un logiciel gratuit et libre pour créer, éditer et archiver des arbres phylogénétiques : cladogrammes, dendrogrammes, chronogrammes et romérogrammes. Il fonctionne sur Windows, macOS et Linux.

**Site officiel et téléchargement : https://mistytoonz.github.io/CladisTree/**

*CladisTree is a free, open-source application for building, editing and archiving phylogenetic trees (cladograms, dendrograms, chronograms and romerograms) on Windows, macOS and Linux. Website and downloads: https://mistytoonz.github.io/CladisTree/*

## Fonctionnalités

- Construction d'arbres au clavier, glisser-déposer des taxons, cadres pour les groupes monophylétiques et paraphylétiques
- Fiches taxons : statut, rang, auteur, période, diagnose, synapomorphies, bibliographie, images multiples, sons, export PDF
- Trois dispositions : cladogramme, dendrogramme et chronogramme calé sur la charte chronostratigraphique internationale (ICS)
- Romérogrammes (diagrammes en fuseaux) calculés automatiquement à partir des âges des taxons
- Classifications alternatives d'un même groupe dans un seul fichier
- Import Newick, NEXUS (Mesquite) et TNT avec valeurs de support ; export Newick, NEXUS, PNG, JPEG, SVG et PDF
- Interface en français, anglais, espagnol, portugais, italien et allemand

## Téléchargement

Les installateurs de chaque version sont disponibles dans les [releases](https://github.com/MistyToonz/CladisTree/releases/latest) et sur le [site officiel](https://mistytoonz.github.io/CladisTree/).

## Compiler depuis les sources

```
npm install
npm start        # lancer en mode développement
npm test         # lancer les tests
npm run make     # créer l'installateur
```
